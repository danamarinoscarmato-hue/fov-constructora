Generación de renders (Gemini API)

La API key se guarda solo en este dispositivo/navegador (no se sincroniza), para no compartirla por accidente. La conseguís gratis en aistudio.google.com/apikey. Cada imagen generada tiene un costo pequeño (aprox. entre USD 0,02 y 0,15 según el modelo y la resolución) que se cobra en tu cuenta de Google AI — necesita facturación habilitada para generar imágenes.
